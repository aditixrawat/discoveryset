# Rare Axis — The Lineup / V9 Commerce Cut

Open `index.html` in a browser. The page uses plain HTML, CSS and JavaScript.

## Page order

1. Product screen with the open set, closed set and all eight sampler images.
2. Scroll-held case film: settle, light pass and controlled opening.
3. Scroll-held spray sequence across all eight fragrances.
4. Three neutral A+ placeholders for trial, card reveal and the full case.
5. Product close with the complete set.

## Visual system

- Black lacquer, warm ivory and coated paper.
- Each scent background keeps enough colour and light to remain readable.
- Small type, thin rules and wide spacing replace badges and chips.
- Each fragrance uses the same fixed stage so the set feels like one collection.

## Motion system

- Slow camera push and small angle changes.
- Case crossfade from sealed to open using transparent product cutouts.
- The card coating clears through a moving wet edge tied to scroll.
- Banner, card, scent name and notes change eight times.
- The fixed shop action remains visible without a price.
- Product price is ₹1,290. Add-to-bag controls update the bag state.

## Mobile

- Product imagery takes the first 62% of the screen.
- The card sits high in the spray stage; name and notes sit below it.
- The ten-image thumbnail rail scrolls horizontally in portrait view.
- The shop action respects phone safe areas.

The A+ image fields are layout placeholders. Replace them with approved photography without changing their aspect ratios or mobile order.
